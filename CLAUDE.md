# CLAUDE.md — памятка для Claude Code

Игра про деградацию: браузерная онлайн-RPG. Замысел — `docs/DESIGN.md` (сжатая копия; полная версия
в claude.ai, ссылка внутри). Запуск и устройство кода — `README.md`. Как рисовать графику — `docs/ART_GUIDE.md`.

## Как работать с Фимой

- Перед каждым действием (правка файлов, команды, установка пакетов) коротко скажи, что собираешься
  сделать, и дождись «давай». Появились вопросы — спрашивай.
- Пиши по-русски, неформально, с матом и рандомными словами — Фима так лучше воспринимает.
  Без старославянщины. Сначала объясняй на пальцах, потом точно.
- Фима на Windows: команды давай для cmd. Игру он запускает двойным щелчком по `START.cmd`.
- Поменялось решение по дизайну — обнови `docs/DESIGN.md` и полную версию в claude.ai (ссылка в нём).
- Коммит — после каждого шага. Пуш — только когда Фима скажет. Исключение — облачная сессия на claude.ai/code:
  она временная, поэтому там пушим после каждого шага. Работаем и пушим в ветку этапа (сейчас `etap-2`),
  не в `main`; в `main` этап вливает Фима.

## Правила кода

- **Сервер решает всё.** Чего персонаж не знает или видит иначе, сервер просто не присылает
  (иначе вытащат через F12). Визуальные искажения — на клиенте.
- Правила, нужные и серверу, и клиенту (движение и т. п.), живут в `shared/` — один код на обоих.
  Предсказание клиента должно совпадать с сервером: счётчик «поправок» в отладке (F3) — 0.
- Никакой записи чисел вида 1e-8 в коде и выводе программ — только обычные десятичные.
- Комментарии и тексты интерфейса — по-русски.
- После любых правок `npm run check` и `npm test` должны быть зелёными. Новая механика — новый тест.
  Тестовые боты — `server/test/bot.ts`.
- `START.cmd` — только переводы строк CRLF и UTF-8 без BOM (первая строка `@echo off`, вторая `chcp 65001`).
  Иначе на Windows вылезут кракозябры или батник сломается. В батнике не используй `&`, `|`, `<`, `>`, `%`, `^`
  внутри текста `echo`.
- Карта — буквами в `shared/src/map.ts`. Числа (скорость, тик, размеры) — `shared/src/constants.ts`.
  Лор книг пишет Фима в `content/books/*.txt`; ты делаешь заготовки.
- Графика: пиксель-арт, плитка 32 × 32, персонаж 32 × 48 (3 кадра × 4 направления), файлы в
  `client/public/assets`. Рисованные искажения — прозрачные PNG поверх мира. Рисует Фима; ты делаешь
  заглушки и говоришь точные размеры. Новые картинки добавляй в проверку размеров в `BootScene`.

## Как устроена связь

- Сервер: Node.js + ws, тик 20 раз в секунду, бюджет движения против ускорения, очередь до 20 нажатий,
  раз в 5 секунд пингует соединения и выкидывает мёртвые.
- Клиент: предсказание своего движения и сверка по `ack`, чужие — интерполяция с задержкой 100 мс.
  Связь пропала — сам переподключается под тем же именем (имя в `sessionStorage`), после перезагрузки
  страницы заходит сам.

## Стек

TypeScript 7, npm workspaces (`shared`, `server`, `client`). Клиент — Phaser 4 (`render.smoothPixelArt`,
камера ×2) и Vite 8. Node.js 22.12 или новее. Порты: 5173 — Vite, 2567 — сервер.

## Команды

- `npm run dev` — сервер и страница, открывать http://localhost:5173
- `npm test` — 54 теста: карта, движение, деградация, сбор и приедание, библиотека и зелье, чат, шкала, помехи,
  сервер с ботами, стресс (читеры, плохая сеть, спам, толпа, призраки). Общие помощники тестов —
  `server/test/helpers.ts` (мир с ручными часами, ходьба по точкам).
- `npm run check` — проверка типов
- `npm run build`, затем `npm start` — всё на одном порту 2567
- На GitHub при каждой заливке то же самое гоняется на Windows и Linux (`.github/workflows/check.yml`).

## Где мы

Этап 1 (каркас) готов и перепроверен. Этап 2, ядро деградации, готов (см. «Этапы» в `docs/DESIGN.md`).
Дальше этап 3, вещи: план шагов предложить Фиме и ждать «давай». Каждый шаг — после «давай» Фимы.

Что где после этапа 2:
- модель деградации (истинная, текущая, зелья, память по имени) — `server/src/degradation.ts`;
- сбор по E, приедание, шахта, отладка `/дег` — `shared/src/resources.ts`, `server/src/gathering.ts`, `World`;
- шкала, которая врёт (черновик), — `server/src/scale.ts` решает число, `client/src/ui/mind.ts` рисует;
- библиотека и зелье — `World.openBook`/`drinkPotion`, книги — `content/books/*.txt`, разбор — `server/src/books.ts`;
- искажение текста (книги, чат, имена) — `shared/src/distort.ts`; чат — `World.sendChat`;
- помехи по порогам (черновик) — таблица `shared/src/effects.ts`, рисуют `client/src/ui/haze.ts`
  и `WorldScene` (имена над головами, ведьминские знаки на стенах).
