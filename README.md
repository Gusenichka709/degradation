# Игра про деградацию — прототип

Онлайн-RPG, где уровень растёт как обычно, а знания и восприятие деградируют.
Замысел целиком — `docs/DESIGN.md` (полная версия в claude.ai: https://claude.ai/artifact/KxQzgy3SVXPCJ2k8aPHMt7).

**Сейчас — этап 2, ядро деградации.** Есть деревня, по ней ходят игроки и видят друг друга, есть чат,
прицел мышью и имена над головами. Кусты, камни и шахту можно собирать по E — от этого растёт деградация,
и чем монотоннее долбишь одно и то же, тем быстрее («приедание»).

## Что поставить один раз

1. **Node.js 22 или новее** — с сайта nodejs.org, кнопка с надписью LTS. В установщике везде «Next».
   Галку «Automatically install the necessary tools» **не ставь** — она полчаса качает то, что игре не нужно.
2. **Git** — с сайта git-scm.com. Нужен, чтобы заливать код на GitHub.

Уже стоит старый Node? Набери в командной строке `node -v`. Если меньше `v22.12` — поставь свежий LTS поверх.

## Запуск — двойной щелчок

1. Распакуй архив, например, в `C:\games` — получится папка `C:\games\degradation-game`.
2. Дважды щёлкни **`START.cmd`** в этой папке.
   В первый раз он минуту-две качает библиотеки, потом запускает игру и сам открывает браузер.
3. Введи имя — ты в мире. Второй игрок — ещё одна вкладка с адресом **http://localhost:5173**
   и другим именем.
4. Остановить игру — закрой чёрное окно.

Windows может спросить, разрешить ли Node.js доступ к сети, — нажми «Разрешить доступ».

## Запуск руками (если двойной щелчок не нравится)

Открой папку игры в Проводнике, щёлкни по адресной строке, напиши `cmd`, нажми Enter. В чёрном окне:

```
npm install
npm run dev
```

Первая команда нужна один раз. Потом открой http://localhost:5173.
Остановить — **Ctrl+C**; если cmd спросит «Завершить выполнение пакетного файла [Y(да)/N(нет)]?», нажми Y.

## Если что-то не так

| Что видишь | Что делать |
| --- | --- |
| «npm не является командой» | Node.js не поставился или окно открыто до установки: закрой окно и открой новое |
| «У тебя Node.js …, а игре нужен 22.12» | поставь свежий Node.js LTS с nodejs.org |
| «Порт 2567 занят» | игра уже запущена в другом окне — закрой его |
| В игре «Переподключаюсь…» | сервер перезапускается (например, Claude поправил код) — подожди, игра вернёт тебя сама |
| Внизу справа «С картинками что-то не так» | нарисованная картинка не того размера — там же написано, какой нужен |

## Управление

| Клавиша | Что делает |
| --- | --- |
| W A S D или стрелки | идти |
| мышь | прицел; персонаж поворачивается к нему |
| E | собрать куст, камень или шахту рядом |
| Enter | написать в чат, Enter ещё раз — отправить, Esc — передумать |
| F3 | отладка: FPS, координаты, тик сервера, поправки предсказания |

Для проверки есть команда в чате: `/дег` — показать свою деградацию, `/дег 45` — поставить 45 %.
Работает только на компьютере, где запущена игра; друзья по Wi-Fi её не смогут.

## Играть с другом по одной сети (Wi-Fi)

После запуска в чёрном окне будет строчка `Network: http://192.168.x.x:5173` — дай другу этот адрес.

## Залить на GitHub

Один раз представься Git'у (имя и почта — твои):

```
git config --global user.name "Твоё имя"
git config --global user.email "твоя@почта"
```

Создай на GitHub пустой репозиторий (без README), потом в папке игры:

```
git init
git add .
git commit -m "Этап 1: каркас"
git branch -M main
git remote add origin https://github.com/НИК/РЕПОЗИТОРИЙ.git
git push -u origin main
```

В первый раз Git откроет окно браузера, чтобы войти в GitHub. После каждой заливки GitHub сам
прогоняет проверку на Windows и Linux — результат во вкладке **Actions** репозитория (зелёная галочка — всё ок).

## Как устроен код

```
shared/    общее для сервера и клиента: карта, движение, сообщения, константы
server/    сервер игры: принимает игроков и 20 раз в секунду двигает мир
client/    браузерная часть на Phaser 4: рисует мир, читает клавиши, показывает чат
docs/      дизайн, инструкция по рисованию и схемы раскладки картинок
scripts/   проверка версии Node.js
START.cmd  запуск двойным щелчком
CLAUDE.md  правила для Claude Code
```

**Главное правило: сервер решает всё.** Клиент только сообщает «я жму вправо», а где ты
на самом деле — говорит сервер. Чтобы не ждать ответа, клиент сразу двигает тебя сам тем же
кодом (`shared/src/movement.ts`), а потом сверяется с сервером. Счётчик «поправок» в отладке (F3)
показывает, сколько раз предсказание разошлось с сервером, — в норме там 0, даже при пинге 150 мс.

Чужих игроков клиент показывает на 0,1 секунды в прошлом и плавно ведёт между снимками сервера.
Связь оборвалась — клиент сам переподключается под тем же именем. А сервер раз в 5 секунд проверяет
каждое соединение и выкидывает «призраков» — тех, у кого отвалился интернет.

## Команды

| Команда | Что делает |
| --- | --- |
| `npm run dev` | режим разработки: сервер и страница с автоперезапуском при правках |
| `npm run build`, затем `npm start` | «боевой» режим: всё на одном порту, открывать http://localhost:2567 |
| `npm test` | 35 тестов: карта, движение, деградация, сбор и приедание, сервер с ботами, читеры, плохая сеть, спам, толпа, призраки |
| `npm run check` | проверка типов во всём проекте |

## Где что менять

- **Карта** — `shared/src/map.ts`: деревня нарисована буквами, легенда там же.
- **Скорость, размеры, тик** — `shared/src/constants.ts`.
- **Графика** — `client/public/assets/`, как рисовать — в `docs/ART_GUIDE.md`.
